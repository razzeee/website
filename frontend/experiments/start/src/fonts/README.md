# Inter

Inter 4.001 (`git-66647c0bb`), normal variable weight 100-900, from the Google
Fonts distribution used by the existing site. These seven WOFF2 subsets preserve
the existing font bytes and Unicode ranges while allowing builds without Next's
generated font assets or network font downloads. Vite gives them hashed filenames
for immutable CDN delivery.

Upstream: https://github.com/rsms/inter
